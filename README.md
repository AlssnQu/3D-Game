# 3D-Game: Título (está pendiente)
Videojuego de terror psicológico en primera persona, enfocado en la concientización sobre el acoso escolar, alineado con la ODS 3 (Salud y Bienestar). 
El jugador explora una versión distorsionada y terrorífica de su antigua escuela, recolectando objetos cotidianos que desencadenan recuerdos reprimidos para reconstruir una historia de bullying y confrontar su propia culpa como testigo silencioso. 
Desarrollado en Unity 6 (6000.3.23f1).
